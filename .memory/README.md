# .memory 使用约定

目录结构：`.memory/<YYYYMMDD>/<HHMMSS>-<type>-<slug>.md`

`type` 取值：

| type | 用途 |
|---|---|
| `decision` | 架构/技术选型决策，必须写"为什么"和"否决了什么" |
| `bug` | 缺陷：现象 → 根因 → 修复 → 回归验证 |
| `risk` | 已知漏洞、限制、待验证项（`NEEDS CHECK`） |
| `verify` | 实测数据、复现步骤、结论 |

文件模板：

```markdown
# <标题>
- 时间：YYYY-MM-DD HH:MM (+08:00)
- 类型：decision / bug / risk / verify
- 影响范围：文件/模块
- 关联提交：<commit sha（可后补）>

## 背景
## 结论
## 证据
## 后续
```

规则：
1. 一次决策/一个 bug 一个文件，不写大杂烩。
2. 只记录"后来者不知道就会踩坑"的信息，不抄代码。
3. 涉及凭据时只写"从环境变量读取"，禁止记录任何真实口令、token、密钥。
4. 实测结论必须带数字和复现命令。
